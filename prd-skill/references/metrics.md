# 成功指标参考库

**使用方式**：Step 4 写成功指标时查阅。按产品类型找到对应指标，选择适合的填入 PRD。
**核心原则**：指标必须可测量，不接受「提升用户体验」「增加用户满意度」这类无法量化的描述。

---

## 指标的写法

**✅ 正确**：可测量，有基准值或目标值
```
功能上线后 30 天内，任务创建成功率 ≥ 95%
导出功能平均耗时 < 3 秒（P99 < 8 秒）
功能上线 2 周内，日活用户中使用该功能的比例 ≥ 20%
```

**❌ 错误**：模糊，无法验收
```
用户满意度提升
系统性能更好
用户更容易上手
```

---

## 按产品类型分类

### 效率类功能
适用：任务管理、工作流、自动化、批量操作

| 指标 | 说明 |
|------|------|
| 任务完成率 | 发起操作后成功完成的比例，目标 ≥ 95% |
| 操作耗时 | 关键操作从触发到完成的时间，P50 / P99 |
| 错误率 | 操作失败占总操作次数的比例，目标 < 1% |
| 重试率 | 用户因失败重新操作的比例，目标 < 5% |
| 功能渗透率 | 目标用户群中实际使用该功能的比例 |

### 内容 / 创作类功能
适用：编辑器、文档、内容生成、模板

| 指标 | 说明 |
|------|------|
| 创建完成率 | 开始创建到保存成功的比例 |
| 平均编辑时长 | 用户在功能上花费的时间（过短可能无效，过长可能体验差）|
| 内容复用率 | 使用模板 / 已有内容的比例 |
| 发布 / 提交率 | 创建后实际提交 / 发布的比例 |

### 数据展示 / 分析类功能
适用：报表、看板、数据导出、搜索

| 指标 | 说明 |
|------|------|
| 页面加载时间 | 首屏数据展示时间，目标 < 2 秒 |
| 搜索命中率 | 搜索后找到目标内容的比例 |
| 导出使用率 | 访问页面的用户中使用导出功能的比例 |
| 数据准确率 | 展示数据与实际数据的一致性，目标 100% |

### 协作 / 社交类功能
适用：评论、@提及、共享、权限管理

| 指标 | 说明 |
|------|------|
| 协作参与率 | 有多人参与的项目 / 文档占比 |
| 消息响应率 | @提及后被回复的比例 |
| 权限设置完成率 | 创建内容后主动设置权限的比例 |

### 平台基建类
适用：API、SDK、通知系统、权限系统

| 指标 | 说明 |
|------|------|
| 服务可用性 | SLA，通常要求 99.9% |
| 接口响应时间 | P50 / P99，具体目标视业务而定 |
| 接入方数量 | 上线后 N 周内完成接入的业务方数量 |
| 错误率 | 接口调用失败率，目标 < 0.1% |

---

## 指标选择原则

1. **一份 PRD 不超过 3 个核心指标**——太多说明没想清楚什么最重要
2. **至少有一个指标在上线后 30 天内可以验收**——避免指标遥遥无期
3. **指标要有基准值**——「提升 20%」需要有当前值作为基准，否则无从验证
4. **指标要与功能目标直接相关**——不要用 DAU 来衡量一个导出功能
