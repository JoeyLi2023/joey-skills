# 完成质检清单

## P0 · 缺失等于本次运行无效

- [ ] 每篇新原始文档都有对应的人物摘要节点（标题与文档标题对应）
- [ ] 人物摘要包含所有必填章节：身份、核心框架、关键洞察、金句、关联概念
- [ ] 关联概念里列出的概念文章，都在概念节点下实际存在（不是空引用）
- [ ] 索引文档已追加本次新增的人物条目

## P1 · 明显问题，应在本次修复

- [ ] 没有因为"强行套进已有概念"而丢失文档的独特视角
  - 验证方式：检查人物摘要里是否有"这篇文章独有、但在概念文章里找不到对应"的洞察
- [ ] 新建的概念文章（如有）包含"跨文档共识"章节，而不只是单个人的观点
- [ ] 更新已有概念文章时，没有重复已经写过的内容
- [ ] 概念节点下没有出现两篇语义重复的文章

## P2 · 质量提升项，有余力时处理

- [ ] 人物摘要的金句保留了原文，没有被翻译或改写
- [ ] 索引文档的主题索引部分（如有）也已更新，新概念/洞察已归类
- [ ] 如果有应该新建但因为内容不足暂时没建的概念，在索引的"待补充"部分记录

## 快速检验：本次运行的概念归纳是否合理？

运行完成后，问自己一个问题：

> **如果用户问"XX 概念"，他应该去看哪篇文章？能找到吗？**

- 如果找不到 → 说明概念文章缺失，或者索引没更新
- 如果能找到但内容太浅 → 说明这次 append 没有实质贡献
- 如果找到了，内容有新角度 → 本次运行合格
